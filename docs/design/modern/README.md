# 新设计语言提案（2026-11）

让 iOS App 更现代的两个视觉方向，只是设计稿，没有改任何代码。

- [`index.html`](index.html)：原则、配色、字体、间距、动效，以及每个方向 7 帧（概览首屏、概览下滑、流水、记一笔、导入复核、账本助手、收支分析），可切换浅色 / 深色。
- [`previews/`](previews/)：PNG 预览（`cover.png` 首页四联对比，`A-light.png` 等为整组页面）。

## 方向

- **A · 纸本卡片（推荐）**：结平的进化版。保留暖纸底、墨色和青绿 / 赭色方向色、净值下的双线；通栏色带换成 22pt 圆角卡片，加单色分类图标、38pt 大数字、圆头柱和带面积的折线。正文从 IBM Plex Sans 换成系统 SF Pro，Plex Mono 只留给账户路径。
- **B · 清透原生**：冷灰底、群青品牌色、彩色分类圆标与环图、便当式数据方块、SF Pro Rounded 数字。

两个方向都保留现有页面的全部内容，玻璃控件层（顶栏胶囊、标签栏、搜索、底部操作栏、输入框）不变。所有金额为示例数据。
