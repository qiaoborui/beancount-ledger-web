让账本看起来属于 iOS 26，又仍然是一本账

现在的「结平」是印刷账本的思路：没有卡片、没有图标、没有强调色，层级全靠字重和细线。它干净，但在 Liquid Glass 的玻璃栏下面显得平、旧、信息密而难扫。下面是两个更现代的方向。两者都保留现有页面的全部内容（结算区、留存率、收支结算、支出分类、最近流水、导入复核、助手），只改视觉语言。

方向 A · 纸本卡片 推荐

结平的进化版。暖纸底色、墨色和青绿 / 赭色两种方向色都保留，但把通栏色带换成圆角卡片，加入单色分类图标、更大的数字和更圆润的图表。净值下面的双线留着当签名。

  • 和现有玻璃栏、Source Serif 回复、已核平这些已有决定完全兼容
  • 改动集中在颜色 token、卡片容器和行样式，迁移成本最低
  • 依旧克制，适合每天看、数字很多的账本

方向 B · 清透原生

更大胆的换装。冷灰底色、群青强调色、彩色分类圆标、圆体数字、便当式数据方块。看起来像 Apple 钱包和现代记账 App。

  • 辨识度和「新」感最强，图表和分类一眼可分
  • 引入一个品牌色和九个分类色，需要新的配色规则
  • 和现在的品牌气质断开，几乎每个页面都要重画

方向 A · 推荐

纸本卡片

一张卡就是一个结算单元。卡片取代通栏色带和满屏细线，让玻璃栏下面始终只有一种底色在折射；方向色仍然只给金额用，交互用墨色。

原则

  1. 卡片分组，不用线分组。一屏 3 到 5 张卡，卡内行与行之间只用缩进的半像素线。
  2. 数字先行。每张卡最上面是一个大数字，明细在下面。
  3. 方向色只属于金额。收入青绿、支出赭色，按钮和选中态用墨色，不加品牌色。
  4. 图标单色。分类图标统一灰底墨线，帮助扫读，但不抢颜色。
  5. 保留双线。净值和已核平的合计下面仍是那条双线，是结平留下的签名。

方向 B

清透原生

贴近系统原生 App 的做法：冷灰分组底、白卡、一个群青品牌色负责交互和净值卡，分类用彩色圆标区分，数字换成圆体。信息一眼可分，代价是色彩规则变多。

原则

  1. 一个品牌色。群青只用于主按钮、选中态和首页净值卡。
  2. 分类有颜色。每个分类一个固定色相，图标、环图、条形图共用。
  3. 便当式概览。首页用 2 × 2 数据方块代替结算表，点开再看明细。
  4. 圆体数字。金额用 SF Pro Rounded Bold，更友好也更醒目。
  5. 支出不标红。支出保持墨色带负号，红色只留给超预算这类真正的警示。

对比与建议

推荐方向 A。它解决了「不够现代」最直接的几个原因：没有容器、没有图标、数字不够大、图表太硬，同时不推翻已经定下的玻璃控件、Source Serif 回复和两种方向色。方向 B 更醒目，但要为品牌色和分类色重新定一套规则，账本的「核对感」也会变弱。也可以混用：用 A 作为基础，只借 B 的彩色分类图标。
