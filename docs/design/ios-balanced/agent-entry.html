结平 · 账本助手放在哪

现在助手藏在「更多 → 账本工具」里，要点两下才能到。这里比较三种更近的入口。推荐 A：右下角的搜索本来就在每个主页面上，把它变成「搜索流水，或直接问账本」，不加任何新按钮。B 可以和 A 同时做，给想把助手常驻底部的人一个选项。

方案入口好处代价
A 搜索里直接问推荐右下角搜索按钮。输入像问题的句子时，最上面出现「问账本助手」，按「前往」提问每个主页面都有，一下就到；不占标签、不加按钮；搜索和提问本来就是同一个动作「我想找点什么」要判断一句话更像关键词还是问题；关键词时这一行退到不显眼的位置，避免误触
B 放进标签栏可选更多 → 标签栏，把「账本助手」选进 3 个位置之一已有标签配置，改动很小；常驻底部，对话不会因为切页面而离开标签只有 3 个，放进去就要挤掉概览、流水或账户之一，所以不做成默认
C 每页右上角不推荐每个主页面标题旁一个助手按钮，打开时带上当前页面（如「概览 · 10 月」）能问「这一页」：分析页上问「餐饮为什么多」最顺手每页多一个按钮，和结平「不加装饰」的原则冲突；带页面上下文要给每页写摘要。可以以后在分析页单独加

A · 搜索里直接问（推荐）

搜索按钮在 iOS 26 上浮在标签栏右边，每个主页面都看得到。点开后，空状态先给几个常问的问题。输入问题时最上面是「问账本助手」，下面照常列出匹配的流水；输入关键词时，这一行降成普通的一行。

B · 放进标签栏（可选）

作为标签时没有返回按钮，切到别的标签再回来，对话还在。默认不放，在「更多 → 标签栏」里自己选。

C · 每页右上角（不推荐）

画出来作对比。它的长处是能带上当前页面的上下文，这一点以后可以只在收支分析页上做成一个「问问这张图」的链接，不必每页都放按钮。
