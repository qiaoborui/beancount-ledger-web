结平 · 账单导入

这一版重新梳理了导入的流程和信息结构，不只是换玻璃。视觉沿用结平第一批（纸面、墨色、只有进出两个方向色、双线结算区）和 Liquid Glass 控件层（顶部栏、筛选分段、弹窗外壳、底部浮层）。原第一批里的「账单导入复核」两帧是这次核对页的起点，结算区、勾选框、→ 账户行、写入按钮都保留。

新的流程从五步减到三步，绝大多数账单选完文件就直接进入核对：

  1. 选文件或点待处理文件选择、系统分享、Gmail 邮件、上次没核对完的草稿，都从导入首页进入
  2. 自动解析识别渠道、解析、去重；只有缺密码或认不出渠道时才停下来问
  3. 核对先处理待确认的几笔，其余已就绪；批量改标签或分类
  4. 写入前确认看总数和 diff，本地引擎校验通过才写入
  5. 完成归档、索引进度，以及去整理未分类的入口

现有页面盘点

每个现有功能在新设计里都有位置，下表右列写明去处。

导入首页

主按钮固定在底部玻璃浮层，滚动到哪里都能点。最上面是「待处理」：上次没核对完的草稿、从其他 App 分享来的文件、Gmail 收到的账单（可核对、解析中、失败可重试或忽略）合在一个列表里，不再在进入页面时自动弹出草稿。渠道覆盖直接列出每个渠道的状态点，归档记录默认显示最近两条。右上角玻璃按钮收纳 Gmail 连接、立即同步、断开。首次使用时给出各渠道的导出路径。

解析

选完文件立刻开始，不再经过准备页。解析中的页面告诉你正在做什么、接下来会检查什么；智能分类放到核对页后台进行，不让人干等。只有两种情况会停下来：压缩包需要密码，或渠道认不出来。这时原来准备页的渠道选择、密码、基金补差开关出现在这里。

核对

结算区保留在最上面，这是这一页唯一要核平的数字。去重说明、核对提示、导入详情合成一行，展开才看。分段筛选默认停在「待确认」：缺分类或智能分类需要你确认的交易排在前面，建议账户直接显示在行里，点一下采纳。点勾选框决定写不写入，点行其余位置打开编辑。顶部玻璃胶囊里是解析选项和智能分类设置。

批量与编辑

原来展开交易后的「选择为标签操作对象」是第二套勾选，容易和写入勾选混淆。现在批量修改只作用于当前筛选里已勾选的交易，标签、统一分类、全选、全不选都在这一张玻璃弹窗里。编辑弹窗可以上下切换，「保存，下一条」把待确认的几笔一口气处理完；智能建议和参考历史也在这里。改渠道或补差设置会重新生成预览，所以单独放在「解析选项」里，并提示会清除本次修改。

写入与结果

本地账本写入前先给结算区（新增笔数、改动文件、归档），再给 diff。写入中断时，玻璃浮层上方出现状态行，主按钮变成「重新检查保存结果」，不会重复提交。完成页换成结平的双线和结算区，并给出下一步：整理未分类的交易、查看这批流水。不勾选任何交易时只归档原始账单。

需要你决定的几处

选完文件直接解析

省掉准备页这一步。代价是想手动指定渠道时要在核对页的「解析选项」里改，然后重新生成预览。

Gmail 放回页面

代码里 Gmail 自动账单的连接、同步、待核对列表都在，但没有放进导入页面。设计稿把它放回「待处理」和右上角菜单。如果服务器没配置 Gmail，这些行不显示。

重复交易只显示说明

原第一批设计稿写「取消排除后仍可逐条复核」，但目前预览不返回被跳过的重复行，所以这版只展示去重说明。要能逐条恢复，需要改解析引擎。

完成页的两个去处

「整理未分类」打开现有的待整理收件箱；「查看这批流水」需要流水页支持按导入批次筛选，可以第二步再做。
