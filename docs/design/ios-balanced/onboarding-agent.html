结平 · 对话式开账 + 圆润的账本助手

两件事一起改：没有账本时，一打开就是账本助手在问你，接入已有 Git 账本或从零新建都在对话里完成；账本助手整页换成圆润的 Liquid Glass 形状。纸面、墨色、进出两种方向色、字体都不动，只改形状和控件层。

决定做法理由
首次打开本机一本账都没有时，不再显示「账本」库页，整屏就是开账对话；已有账本的人照旧看到账本库，库里「新建账本」也进同一个对话新用户第一眼是一个会提问的助手，而不是一页按钮
开场三条路助手先问一句，下面三张大卡片：接入已有 Git 账本 / 从零新建 / 其他方式（iCloud 云盘、本机文件夹、备份）三条路后面要问的东西完全不同，先分流，后面的问题才问得准
没配模型时开场、选路、Git 接入、其他方式都由 App 自己按脚本问，不需要模型；只有「从零新建」需要模型，到那一步在对话里插一张「接上模型」卡片填 Key有 Git 账本的人不该先去找 API Key；Key 和令牌都只进钥匙串
密码和令牌仓库令牌、API Key 只在对话里的原生卡片输入（SecureField），存钥匙串，从不进对话记录、不发给模型聊天框里打出来的东西会发给模型
需要填数的地方期初余额、分类、存放位置、导入渠道用对话里的卡片（金额输入、可点的分类、选项），文字仍可随时补充或改一串余额靠打字一条条说太累，卡片一屏填完
从零新建要问到的资金账户 → 待还款项 → 币种（有外币才问）→ 收支分类 → 期初余额和日期 → 放在哪（本机 / iCloud / Git）→ 账单从哪来（支付宝、微信、银行、美团…）→ 预览文件并校验 → 创建不是固定顺序：用户一句话说了好几件事就一起记；顶部一条进度胶囊显示哪些齐了
生成的账本main.bean（选项 + include）、accounts.bean（open 指令）、opening.bean（期初余额）、按年的流水文件，加上所选渠道的 imports/*-config.yaml；创建前本机跑一次校验，预览卡里能展开看原文现在全写在一个 main.bean 里，账本大了不好维护
选了 Git 托管新账本创建后推到用户给的空仓库（同一张 Git 卡片，提示「需要一个空仓库」）复用现有「连接 Git」能力，不另做一套
助手页形状问题气泡 20pt 圆角；选项卡、改动卡、记录卡 22pt 圆角卡片，选项是胶囊；按钮都改胶囊；工具调用折叠成胶囊；输入框拆成「+」玻璃圆 + 玻璃胶囊输入条，发送键在胶囊里现在 3pt 小圆角、发丝线分隔和直角按钮跟玻璃的大圆角打架
不变的回答仍直接排在纸面上（不加气泡），Source Serif 阅读字体、金额方向色、iOS 17–25 的平面样式只做液态玻璃化的圆润处理，不换设计语言
要你定的一件事没配模型时怎么开场：我建议开场、选路、Git 接入都由 App 按脚本问（不需要模型），到「从零新建」时再在对话里填 Key。另一种是一打开先要求填模型 Key，之后全部交给模型问。

一、账本助手：从小圆角到圆润玻璃

同一段对话放在一起比：左边是现在的样子，中间和右边是改后的浅色、深色。内容和层级不变，只换形状。

二、没有账本时：一打开就是助手

不再先看到「账本」库页。助手先打招呼并分流；右上角「…」里留着手动开账向导、从 iCloud 云盘加入、从备份恢复，给不想聊的人。选「从零新建」而还没接模型时，对话里插一张卡片把模型接上，不跳去设置页。

三、接入已有的 Git 账本

不需要模型。用户可以直接贴仓库链接，App 认出地址后把它填进 Git 卡片；令牌只在卡片里输入。连上后在对话里逐步显示：下载、找入口文件（有多个候选就让用户点选）、本机校验、建索引，最后给一句账本概况和「进入账本」。

四、从零新建（重点）

助手边聊边改一份草案，顶部一条玻璃进度胶囊显示哪几部分齐了，点它看账本结构。先开放式地问钱放在哪，一句话里提到的卡和钱包一次全记下，再只追问缺的。要填数、要挑的地方用卡片：余额一屏填完，分类点掉不要的。最后预览要生成的文件，本机校验通过才能创建。
