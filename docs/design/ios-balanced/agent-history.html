结平 · 助手历史与思考强度

账本助手的对话不再只活在内存里：每次对话按账本存在本机，可以随时开新对话，也能翻回旧对话接着问。模型设置里加一项思考强度，只列出所选模型支持的档位。

决定做法理由
入口右上角在「新对话」左边加一个历史按钮，点开是底部弹出的列表不离开当前页；和「新对话」放在一起，一眼能看出是同一件事的两面
列表按 今天 / 昨天 / 更早 分组；每行是第一个问题，下面一行是最后的回答或结果，右边时间；当前对话用凹陷底色结平不用卡片；问题本身就是最好的标题，不需要另起名字
存放每个对话一份 JSON，放在这本账本的 runtime 目录下，不进 Git 同步、备份或导出；左滑删除，设置里可以清空和草稿副本同一个位置；账本数据本来就在本机，不会多出一份同步到别处的拷贝
后台中的对话正在回答的对话也在列表里，显示当前步骤；切到别的对话不打断它，答完照常通知和上一阶段的后台运行一致
未写入的草稿离开或重开对话时，没写入的草稿改动放弃，旧对话里留一行说明草稿是对话期间账本的副本，隔一段时间几乎一定过期；直接让助手重做更安全
思考强度模型与密钥里一行「思考强度」：关 / 最少 / 低 / 中 / 高 / 超高 / 最大，按模型列出；默认「中」；输入框上方和回答页脚写出当前档位不同模型档位不同，只显示能用的；换模型时自动取最接近的一档
自定义服务自定义接口也能选档位，但只给到「高」；服务不支持时由服务端忽略自建网关无法事先知道模型是否支持推理

历史对话

右上角三个按钮：历史、新对话、模型与密钥。历史从底部弹出，点一行切过去，左滑删除。

旧对话与思考强度

重开旧对话能接着问。没写入的草稿改动会被放弃并留一行说明。思考强度只列出当前模型支持的档位。
