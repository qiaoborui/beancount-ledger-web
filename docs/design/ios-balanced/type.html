结平 · 照 Claude 的样子排中文

先说结论：Claude 网页和 App 上那种舒服的中文，用的就是苹方。Anthropic 自己的字体（Anthropic Sans / Serif / Mono）只覆盖拉丁字母和数字，中文全部落到系统的苹方上。结平现在的中文也是苹方，所以差别不在中文字体本身，而在三件事：

  1. 字重轻。Claude 的正文和列表标题都是常规体（400），层级靠字号和颜色。结平的流水、账户名用的是苹方中黑（500），一屏下来偏重。
  2. 行距松。Claude 的回答是 16pt、约 1.7 倍行高。结平助手回答是 15pt、约 1.6 倍。
  3. 西文用衬线。Claude 回答里的英文、数字是衬线体，和苹方混排时西文显得更“书面”，中文反而显得更干净。Anthropic Serif 不对外授权，最接近又能合法打包的是 Source Serif 4（OFL 授权）。

推荐 方案 A：中文保持苹方，界面字重减一档，助手回答换成「Source Serif 4 + 苹方」、16pt、1.75 倍行高。这就是 Claude 实际的搭配，App 只多约 0.5 MB。方案 B 在此基础上把标题和回答的中文换成思源宋体，更有书卷气，但离 Claude 远了一步，还要多带 5 MB 左右的字体。

调研

Claude / Anthropic 现在用的字体，以及哪些能放进结平

Claude 的字体

2025 年起 claude.ai 用自有的 Anthropic Sans（界面、用户消息）、Anthropic Serif（回答、大标题）、Anthropic Mono（代码）。更早是 Styrene B + Tiempos / Copernicus。都是商业或自有字体，不能打包进别的 App。

Claude 的中文

Anthropic 的字体只有拉丁字符。回答区的字体栈里，中文段落排在第一位的是 PingFang SC，其次是微软雅黑、Noto Sans CJK。所以苹果设备上 Claude 的中文就是苹方。社区里有插件把它换成思源宋体，正是因为原生是黑体。

能合法打包的

Source Serif 4、Newsreader（西文衬线，OFL）；Noto Serif SC / 思源宋体（中文衬线，OFL）。苹方是系统字体，直接用，不打包也不能打包。
