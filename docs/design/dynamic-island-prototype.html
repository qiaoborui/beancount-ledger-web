动效规格

起点硬件岛 126 × 37，顶部 y = 11，形状始终顶部锚定、胶囊圆角 min(h/2, 42)
展开 352 × 84宽 spring(0.46, 0.70)
高 spring(0.54, 0.76) —— 宽先于高，形成「横向甩出」
内容入场以岛中心为锚：blur 10→0、scale .86→1、opacity，spring(0.42, 0.90)；徽标 / 文字 / 金额错开 0 / 50 / 90ms。布局按最终尺寸计算并随形状比例映射，不发生文字重排
金额逐位滚动 spring(0.62, 0.82)，每位错开 30ms；导入为真实里程表进位计数
确认进度环 0.22–0.62s，随后徽标被强调色实心圆「绽放」覆盖 spring(0.38, 0.62)，白色对勾描边 0.26s，外环扩散消失；此刻触发 .success 触感
紧凑态2.3s（导入 3.0s）后内容 160ms 模糊退场，形状 spring(0.42, 0.82) 收为 宽 × 37：左对勾、右金额，停留 1.5s
收回宽 spring(0.40, 0.88) / 高 spring(0.34, 0.90) 回到硬件岛，状态栏同步淡入
打断新通知直接重定向目标值，弹簧保留当前速度；旧内容 160ms 退场，新内容延后 100ms 入场
减弱动态无模糊 / 缩放，形状使用临界阻尼，内容纯淡入淡出

按键 1–5 触发，S 慢放，空格暂停。
